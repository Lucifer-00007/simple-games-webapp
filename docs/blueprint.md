# **App Name**: GameVerse

## Core Features:

- Game List Display: Display a dynamically loaded list of games from the specified GitHub repository.
- Real-time Game Search: Implement a search bar for filtering games by name.
- Responsive Layout: Ensure the layout adapts seamlessly across various device sizes and screen resolutions.
- Game Data Fetching: Retrieve game data (name, description, thumbnail) from `https://github.com/he-is-talha/html-css-javascript-games`.
- AI Game Recommendations: Suggest related games based on user search history, powered by an AI tool that will decide if similar search terms are present.

## Style Guidelines:

- Background color: Dark, near-black background (#121212) for a modern, immersive feel.
- Primary color: Electric Blue (#7DF9FF) to draw attention and establish visual interest.
- Accent color: Vibrant Purple (#BE29EC) as a secondary accent for interactive elements.
- Font pairing: 'Space Grotesk' (sans-serif) for headlines and 'Inter' (sans-serif) for body text, ensuring readability and a contemporary aesthetic.
- Use clean, minimalist icons in electric blue and purple to represent game categories and interactive elements.
- Employ a grid-based layout to showcase games, ensuring content is organized and easily navigable on all devices.
- Incorporate subtle transition animations and hover effects to enhance user engagement and provide feedback on interactions.
